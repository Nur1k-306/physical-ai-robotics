# PandaPickCube

Учебный проект курса Яндекс Практикума «Физический ИИ (роботикс)». В симуляции MuJoCo манипулятор Franka Panda учится захватывать куб и перемещать его к цели. Политика обучается методом PPO с RSL-RL.

Исходный код симуляции и обучения взят из [учебного шаблона Яндекс Практикума](https://github.com/Yandex-Practicum/ap-physicalai-1). Здесь собраны результаты и материалы для воспроизведения практик.

## Материалы практик

- [Практика 1](Practice_1/README.md) — устройство проекта, обучение и запуск сохранённой политики.
- [Практика 2](Practice_2/README.md) — пять CPU-экспериментов, сравнение кривых обучения и проверка финальных моделей.
